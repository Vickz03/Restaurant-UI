# AARAYA — Artisanal Fine Dining & Culinary Art

A production-quality, luxury fine-dining restaurant web application built with **React 18**, **Vite**, **Tailwind CSS**, and **React Router DOM**.

---

## 🍷 Brand Overview

- **Restaurant Name**: AARAYA
- **Tagline**: Artisanal Fine Dining & Culinary Art
- **Location**: 12 Cathedral Road, Chennai, Tamil Nadu
- **Aesthetic**: Dark cinematic visual language, warm ivory typography, muted gold accents, and high-resolution culinary photography.

---

## 📱 Pages & Routes

1. **Home (`/`)**: Full-screen cinematic hero, restaurant philosophy, signature dishes showcase, executive chef profile, curated experiences, and table reservation CTA.
2. **Menu (`/menu`)**: Dynamic category filter tabs (Signature, Starters, Mains, Desserts, Wine & Pairings) with editorial dish listings, prices, and dietary tags.
3. **Our Story (`/story`)**: Restaurant history, Chef Arjun Rao's 20+ years culinary background, 3 core philosophy pillars (Seasonality, Craft, Sustainability), and brand story.
4. **Reservation / Experience (`/reservation`)**: Interactive table booking form with guest size selector, date picker, time slot buttons (7:00 PM - 9:00 PM), occasion options, and client-side confirmation modal.
5. **Gallery (`/gallery`)**: Asymmetric masonry image grid with category filtering (All, Food, Interiors, Chef, Experience) and fullscreen lightbox with keyboard navigation.
6. **Events / Private Dining (`/events`)**: Bespoke private dining, corporate event, and chef's table package cards with an integrated inquiry form.
7. **Contact (`/contact`)**: Location details, operating hours, direct concierge form, and interactive styled map section with Google Maps directions link.

---

## 🛠 Tech Stack & Architecture

- **Framework**: React.js 18 + Vite
- **Styling**: Tailwind CSS with custom theme design system (`#0B0B0A`, `#151513`, `#1B1A17`, `#F5F1E8`, `#B89B62`)
- **Typography**: Google Fonts — *Cormorant Garamond* (Serif Headings) & *Inter* (UI Controls / Body)
- **Icons**: Lucide React
- **Routing**: React Router DOM v6
- **Animations**: CSS transitions & Framer Motion micro-interactions

---

## 🚀 Setup & Execution Instructions

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run local development server:
   ```bash
   npm run dev
   ```

3. Build production bundle:
   ```bash
   npm run build
   ```
